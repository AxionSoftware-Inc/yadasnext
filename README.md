## Ishga tushirish

`index.html` faylini brauzerda oching. GitHub Pages yoqilgach, sayt avtomatik ravishda repository sahifasida ishlaydi.

Sayt ichidagi ma’lumotlar:

- `questions.js` — sayt tez va lokal ochilishi uchun tayyorlangan savol ma’lumotlari;
- `questions-1-80.json` — 1–80-sahifalarning mavzular bo‘yicha birlashtirilgan JSON’i;
- `data/` — 4 ta manba JSON va birlashtirilgan nusxa.

## GitHub Pages

1. Shu papkaning ichidagi barcha fayllarni GitHub repository’ga push qiling.
2. Repository’da `Settings → Pages` bo‘limiga kiring.
3. `Deploy from a branch` ni tanlang.
4. Branch sifatida `main`, papka sifatida `/ (root)` ni tanlang.

Sayt build jarayonini talab qilmaydi; `index.html` to‘g‘ridan-to‘g‘ri GitHub Pages’da ochiladi.
